# SmartMove Database Backups

Store sanitized database exports for coursework demonstration here.

Suggested structure:
- `oracle/` — Oracle schema SQL exports or Data Pump backups.
- `mongodb/` — MongoDB JSON/BSON exports.

Do not commit passwords, connection strings with credentials, real personal data, or secrets. This repository is public. Large binary backups may exceed GitHub upload limits. Database backups are separate from application source code.
